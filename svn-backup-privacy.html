プライバシーポリシー

せとSVNバックアップのデータの取り扱い

作成日：2026年10月26日 · 設定準備中

本ポリシーは、現在準備中の個人利用構成を説明します。公開・運用開始前に、実際の設定と内容が一致していることを確認します。

1. 対象と利用目的

「せとSVNバックアップ」は、所有者本人がWindows上のSVNリポジトリをバックアップ・復元するために使用します。データは、バックアップの作成、保存、確認、復元、保持期間に応じた整理に限って利用します。

本アプリの運用者は、取り扱うデータを販売したり、広告配信や機械学習モデルの学習に利用したりしません。他の利用者向けのデータ収集サービスではありません。

2. 扱うデータと保存場所

Windows PC内

  • 元のSVNリポジトリと、hotcopyで作成するバックアップ用コピー。これらはresticの暗号化によって自動的に暗号化されるものではありません。
  • バックアップ処理に必要な設定、resticのキャッシュや実行ログ。構成に応じてファイルのパスや処理日時などを含む場合があります。
  • Google Driveへのアクセスに必要なOAuthトークンなど、ローカルのrclone設定に保存される認証情報。

本人のGoogle Drive内

resticで暗号化したバックアップデータと、復元・管理に必要なresticリポジトリの管理用ファイルを保存します。元のSVNファイルを平文のままアップロードする構成にはしません。

暗号化しても、保存されるオブジェクトのサイズ・数・更新日時など、ストレージ側で扱う情報まで隠されるわけではありません。

3. Google APIの権限

使用するスコープは https://www.googleapis.com/auth/drive.file です。本アプリが作成したファイル、または利用者が本アプリでの使用を許可したファイルについて、バックアップの保存・復元・整理に必要な作成、閲覧、更新、削除を行います。Drive全体への包括的アクセスを求めるものではありません。

Gmailのメール、Googleカレンダーの予定は取得しません。それらのAPI権限も要求しません。

4. 保護と外部サービス

バックアップはresticで暗号化し、rcloneからGoogleへの通信にはHTTPSを使用します。Google Driveに保存したデータは、同サービスの保存・運用の仕組みに従って扱われます。

ローカルのrclone設定やOAuthトークンは、第三者に渡さず、Windowsのアクセス権などで保護する必要があります。この構成では、認証情報がDPAPIで保護されることや、設定ファイル自体が暗号化されていることを前提にしません。

resticのパスワードはバックアップ本体と分けて安全に保管してください。利用できるパスワードをすべて失うと、暗号化済みデータを復元できません。暗号化だけで、端末の侵害や誤削除などすべてのリスクを防げるわけではありません。

5. 権限の取り消しとデータの削除

Googleアカウントの「サードパーティとの接続」から本アプリへのアクセス権を取り消せます。取り消し後は、再認証するまで新たなDriveへのアクセスができなくなります。

権限を取り消すだけでは、すでに保存したDrive上のバックアップや、PC内のコピー・設定・ログは削除されません。

  • 保存済みバックアップは、本人がrestic・rcloneまたはGoogle Driveの管理画面で必要な削除操作を行います。Driveのゴミ箱に残る場合は、その状態も確認します。
  • ローカルのコピー、キャッシュ、ログ、不要な認証設定は、本人が保存先を確認して別途削除します。
  • resticのリポジトリ内のファイルを個別に手動削除すると、他のバックアップも復元できなくなる可能性があります。世代整理にはresticの適切な手順を使用し、全削除は復元が不要であることを確認してから行います。

保持期間と削除時期は本人が決定します。現段階で、自動削除や定期実行が稼働済みであるとはしていません。

6. この説明サイトについて

このサイトは静的な説明ページです。独自の入力フォーム、アクセス解析、広告、トラッキング用スクリプトは設置しません。バックアップデータ、OAuthトークン、パスワードはこのサイトに保存・公開しません。

GitHub Pagesに公開する場合、ホスティング事業者のGitHubが、サービス提供やセキュリティのためにIPアドレスなどのアクセス情報を記録する場合があります。

7. 変更・お問い合わせ

用途やデータの取り扱いを変更する場合は、このページの内容を更新します。

お問い合わせ先は、GoogleのOAuth同意画面に表示される「ユーザーサポートメール」です。このページに個人の連絡先は掲載しません。
